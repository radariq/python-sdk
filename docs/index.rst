Welcome to RadarIQ's Python documentation
==========================================

This module provides an easy to use Python 3 wrapper for the RadarIQ-M1_ module. It uses uses pySerial for
serial communication and runs on Windows, OSX, and Linux

Requirements
============
- Python_ 3.4 and newer
- A RadarIQ-M1_ module (or later)

.. _Python: https://www.python.org
.. _RadarIQ-M1: https://maker.raderiq.io

Installation
============

Install the RadarIQ wrapper using pip
``pip install radariq``

The package can be used from Python scripts (``import radariq``).

See the getting started guide or examples directory for more details
